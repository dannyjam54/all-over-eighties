ALL OVER 80'S – BOOKING FORM SETUP

The booking form has been switched from FormSubmit to Web3Forms. This works with a static GitHub Pages website and sends submissions to your email without needing a web server.

ONE-TIME SETUP
1. On your computer, go to https://web3forms.com/
2. Choose Create Access Key.
3. Enter dannyjam54@gmail.com.
4. The access key has already been added to bookings.html in this package.
5. Upload/commit the website files to the root of your GitHub repository, replacing the existing files.
6. Visit https://allovereighties.co.uk/bookings.html and submit a test enquiry. Check the inbox and spam folder for the email address linked to your Web3Forms access key.

IMPORTANT
Do not send the access key to anyone or post it publicly. It is designed to be used in the website form, but treat it like a private setup credential.

The access key is installed in bookings.html. Keep it in the website code for the form to work. The recipient address is managed by Web3Forms for this access key.

Official setup guide: https://docs.web3forms.com/getting-started/installation
